# Set Infiltration Rate

Dokuz SpaceInfiltration:DesignFlowRate nesnesini tek carpanla olcekler. Model iki yontem karistiriyor: bes nesne AirChanges/Hour, dort nesne Flow/ExteriorArea. Carpan tohum modele goredir; her kosu tohumdan basladigi icin sonuc belirlenimlidir.

## Argumanlar

- `infiltration_multiplier` (Double, varsayilan `1.0`) — Infiltration multiplier

Karar degiskeni tanimi: `engine/parameters.py`.
