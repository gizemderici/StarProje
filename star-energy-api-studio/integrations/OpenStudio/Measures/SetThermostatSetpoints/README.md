# Set Thermostat Setpoints

Sekiz bolgenin termostatini sabit isitma/sogutma ayar noktasina ceker. En az 0,5 K olu bant sart kosulur.

## Argumanlar

- `heating_setpoint_c` (Double, varsayilan `22.0`) — Heating setpoint (C)
- `cooling_setpoint_c` (Double, varsayilan `24.0`) — Cooling setpoint (C)

Faz 2 kapsaminda yazildi. Karar degiskeni tanimi:
`engine/parameters.py`.
