# Set Window Construction

Modeldeki yedi hazir pencere konstruksiyonundan birini 114 pencerenin tamamina uygular. Hem dogrudan atamalari hem varsayilan alt yuzey setini gunceller.

## Argumanlar

- `target_construction` (String, varsayilan `penc_std_4mm`) — Target glazing construction

Faz 2 kapsaminda yazildi. Karar degiskeni tanimi:
`engine/parameters.py`.
